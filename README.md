# Reader Pet · 九十九夜梦

居住在作家先生/作家小姐设备中的桌宠读者。

> 「请不要在意我，尽管按照您的心意去书写吧。无论是喜悦还是悲伤，是平淡还是激昂，只要是您亲手编织的未来，我都会认真地阅读下去。」

## 设计要点

- **4 套人设**：读者 / 心爱的少女 / 开朗的少女 / 怪人
- **五层记忆架构**：Profile + 近期窗口 + Episode 日志 + 语义事实 + 任务日志
- **双权限模式**：安全模式（默认）/ 危险模式（10s 阅读倒计时确认）
- **Claude Code 桥接**：通过 Stop hook 接收任务完成事件，由桌宠汇报
- **可选 GPT-SoVITS 语音**：本地 TTS，独立进程
- **全部 API 用户自填**：不分享开发者 key
